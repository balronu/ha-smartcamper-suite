# SmartCamper Suite v0.3.0-beta.2

## Deutsch

### Status

`v0.3.0-beta.2` ist die zweite öffentliche Test-Beta. Sie enthält die
README-, Screenshot- und Branding-Korrekturen für die kontrollierte HACS-
Erprobung der drei Suite-Module. Die Stable-Einzelintegrationen bleiben die
Produktionsreferenz.

### Änderungen

- deutsche Haupt-README vollständig überarbeitet und mit Sprachwahl versehen;
- vollständige englische README synchronisiert;
- HACS-Installationsschritte, Home-Assistant-Einrichtung, Lovelace-
  Konfiguration, parallele Stable-Installation und getrennte Journal-
  Datenbank dokumentiert;
- echte Chromium-Fixture-Screenshots für Tankstellen, Route Planner,
  Travel Journal und Karten-Konfiguration hinzugefügt;
- Browser-Fixture so korrigiert, dass die gebündelten Anbieterlogos über den
  simulierten Suite-Static-Path geladen werden;
- fehlender Fahrzeugverwaltungs-Screenshot ausdrücklich als nicht verfügbar
  dokumentiert, statt eine Ansicht zu erfinden;
- lokales HA-Branding und die getrennte HACS-/CDN-Grenze dokumentiert.

### Installation

In HACS Vorabversionen aktivieren, `balronu/ha-smartcamper-suite` als
Integration hinzufügen und `v0.3.0-beta.2` auswählen. Nach dem Neustart einen
separaten Suite-Config-Entry anlegen. Die drei Stable-Integrationen bleiben
installiert und unverändert.

### Einschränkungen

- Test-Beta, keine Stable-Version und nicht für VM 104 freigegeben;
- Nakordoni-Motorhome-Routing und echte Providerquoten nicht produktiv
  verifiziert;
- Legacy-Journal-Import zunächst ausschließlich als Dry-Run mit Kopie oder
  synthetischer Fixture;
- keine automatische Migration bestehender Dashboards, Automationen,
  Config Entries oder Datenbanken;
- Fahrzeugverwaltung ist durch HA-Fixture-/Config-Flow-Tests abgedeckt, aber
  noch nicht als echter HA-UI-Screenshot erfasst;
- HACS-Repositoryanzeige und offizielles Home-Assistant-CDN-Branding sind
  getrennte Zustände und nicht automatisch gleichbedeutend.

## English

### Status

`v0.3.0-beta.2` is the second public test pre-release. It contains the README,
screenshot, and branding corrections for controlled HACS testing of the three
Suite modules. The standalone Stable integrations remain the production
reference.

### Changes

- fully revised German primary README with language selector;
- synchronized complete English README;
- documented HACS installation, Home Assistant setup, Lovelace configuration,
  side-by-side Stable installation, and the separate journal database;
- added real Chromium-fixture screenshots for fuel stations, Route Planner,
  Travel Journal, and card configuration;
- fixed the browser fixture so bundled provider logos load through the
  simulated Suite static path;
- explicitly documented the unavailable vehicle-management screenshot instead
  of fabricating one;
- documented local HA branding and the separate HACS/CDN boundary.

### Installation

Enable pre-releases in HACS, add `balronu/ha-smartcamper-suite` as an
Integration, and select `v0.3.0-beta.2`. After restarting Home Assistant,
create a separate Suite Config Entry. Keep all three Stable integrations
installed and unchanged.

### Limitations

- test pre-release, not Stable and not approved for VM 104;
- Nakordoni motorhome routing and real provider quotas are not production
  validated;
- legacy journal import is initially limited to a dry-run against a copy or
  synthetic fixture;
- no automatic migration of existing dashboards, automations, Config Entries,
  or databases;
- vehicle management is covered by HA fixture/Config Flow tests but is not yet
  captured as a real HA UI screenshot;
- HACS repository presentation and official Home Assistant CDN branding are
  separate states and are not automatically equivalent.
