# SmartCamper Suite v0.3.0-beta.3

## Deutsch

Hotfix für die erste Bedienbarkeitsprüfung der Suite.

- Der Config Flow führt jetzt durch Fahrzeug/GPS, Provider, Module und gemeinsame Einstellungen.
- Der Options Flow erlaubt die Bearbeitung dieser Werte; `device_tracker.wohnmobil_zoe` kann als Tracker ausgewählt werden.
- Die drei öffentlichen Module sind Travel Journal, Mobile Fuel Stations und Camper Route Planner. Wartezeiten Forecast wird nicht mehr angeboten.
- API-Schlüssel bleiben im Config Entry; der Legacy-Journal-Import bleibt standardmäßig deaktiviert und Dry-Run-only.
- Nakordoni-Motorhome-Routing bleibt Beta und wird nicht als rechtlich validierte Navigation dargestellt.
- Die zentrale `custom:smartcamper-card` ist im HACS-Paket enthalten, wird beim Setup als zusätzliche Lovelace-Ressource registriert und enthält Picker-Metadaten sowie den visuellen Editor.
- Browser- und HA-Fixtures prüfen Registrierung, drei Modulansichten, Responsive-Karte, Flow-Sequenz, Reload und Unload.

Dies bleibt eine kontrollierte Beta. Es wurde keine Installation auf VM 104 durchgeführt; produktive Datenbanken und Stable-Integrationen bleiben unberührt.

## English

Hotfix for the first usability validation of the Suite.

- The Config Flow now walks through vehicle/GPS, providers, modules, and shared settings.
- The Options Flow edits those values; `device_tracker.wohnmobil_zoe` can be selected as the tracker.
- The three public modules are Travel Journal, Mobile Fuel Stations, and Camper Route Planner. Border wait times are no longer offered.
- API keys remain in the Config Entry; legacy journal import stays disabled by default and dry-run-only.
- Nakordoni motorhome routing remains beta and is not presented as legally validated navigation.
- The central `custom:smartcamper-card` is included in the HACS package, registered as an extra Lovelace resource during setup, and exposes picker metadata and a visual editor.
- Browser and HA fixtures cover registration, the three module views, responsive rendering, flow sequencing, reload, and unload.

This remains a controlled beta. It was not installed on VM 104; productive databases and Stable integrations remain untouched.
