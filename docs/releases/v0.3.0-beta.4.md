# SmartCamper Suite v0.3.0-beta.4

## Deutsch

Phase-2G-Test-Beta mit verbesserter Provider- und OAuth-Fehlerbehandlung.

### Änderungen

- Tankerkönig-, Petromap- und Nakordoni-Adapter mit synthetischen Erfolgs-,
  Leer-, Authentifizierungs-, Rate-Limit-, Fehler- und Timeout-Tests.
- Provider-Fallback funktioniert auch bei Authentifizierungsfehlern und
  Transport-Timeouts.
- Zwei Fahrzeuge können denselben globalen Provider-Zugang verwenden.
- Cache und Inflight-Deduplizierung verhindern unnötige doppelte Abfragen.
- Nakordoni-PKCE, Token-Erneuerung und Reauth-Pfade bleiben isoliert getestet.
- Vollständiger deutscher und englischer Prüfbericht sowie Live-Testplan.

### Installation und Einschränkungen

In HACS **Vorabversionen** aktivieren und `v0.3.0-beta.4` auswählen. Danach
Home Assistant neu starten und die Suite als separaten Config Entry einrichten.

Diese Beta wurde nicht auf VM 104 installiert. Es wurden keine Live-Provider-
oder OAuth-Aufrufe durchgeführt und keine echten Zugangsdaten verwendet.
Legacy-Import bleibt deaktiviert beziehungsweise Dry-Run-only. Stable-
Integrationen und produktive Daten bleiben unverändert.

Dies ist eine kontrollierte Beta für den manuellen Praxistest, keine Stable-
Version.

## English

Phase 2G test pre-release with improved provider and OAuth error handling.

### Changes

- Synthetic success, empty-result, authentication, rate-limit, error and
  timeout coverage for Tankerkönig, Petromap and Nakordoni adapters.
- Provider fallback now also handles authentication failures and transport
  timeouts.
- Two vehicles can share the same global provider credential.
- Cache and inflight deduplication prevent unnecessary duplicate requests.
- Nakordoni PKCE, token refresh and re-authentication paths remain isolated
  and tested.
- Complete German and English verification report and live-test plan.

### Installation and limitations

Enable **pre-releases** in HACS and select `v0.3.0-beta.4`. Restart Home
Assistant and configure the Suite as a separate Config Entry.

This beta was not installed on VM 104. No live provider or OAuth calls were
performed and no real credentials were used. Legacy import remains disabled
or dry-run-only. Stable integrations and productive data remain unchanged.

This is a controlled beta for manual practical testing, not a Stable release.
