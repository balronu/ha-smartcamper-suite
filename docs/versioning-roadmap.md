# SmartCamper Suite – Zielversionierung

Die Versionsplanung ist eine Roadmap und keine Release-Freigabe:

| Zielversion | Inhalt |
|---|---|
| `v0.1.0` | Grundsystem und Mobile Fuel Stations |
| `v0.2.0` | zusätzlich Camper Route Planner |
| `v0.3.0` | zusätzlich Camper Travel Journal |
| `v0.4.0` | zusätzlich Camper Weather |
| `v0.5.0` | zusätzlich Wartezeiten Forecast |
| `v1.0.0` | vollständig integrierte Suite |

Der Beta-Status einer externen Provider-API ist unabhängig vom Versionsstatus
der Suite. Nakordoni-Motorhome-Routing wird in der Oberfläche transparent als
Beta gekennzeichnet; dies ist kein eigener Suite-Releasekanal.
